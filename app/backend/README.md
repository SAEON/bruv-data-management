## 🛠 Local Development Setup

### 1. Prerequisites
- Python 3.12+
- Node.js 20+

# Backend reamdme

**FastAPI Setup**

Create virtual environment and activate it for backend

`cd app/backend`

# Create virtual environment

`python -m venv venv`


# Activate virtual environment

`source venv/bin/activate`


# Install backend dependencies

`pip install -r requirements.txt`


# Start backend dev server (runs on http://localhost:8000)

`uvicorn main:app --reload`
